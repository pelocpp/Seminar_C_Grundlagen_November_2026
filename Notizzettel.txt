Ablauf / Erstellung eines C-Programms:
--------------------------------------

C ist eine Programmiersprache.
Es gibt viele Analogien zu natürlichen Sprachen:

== Lexikon / Wörterbuch
== Grammatik / Syntax / Rechtschreibung
== Bedeutung / Semantik: Was tut das Programm

Bemerkung:

C ist eine formatfreie Programmiersprache

Die Anweisungen müssen nicht Zeile für Zeile geschrieben werden.


Mehrere Schritte:

A) Quelltext eingeben / Source Code

   Mit einem Editor (Nicht: Word)

B) Vor der eigentlichen Übersetzung:  Läuft ein separates Tool: Präprozessor

   Diese wandelt alle Zeilen um, die mit # anfangen

C) Text für ein C-Programm unterliegt einer Syntax / Grammatik:

   Dies muss überprüft werden: Tool: Übersetzer / Compiler

   1. Ziel: KEINE Fehler, sonst Abbruch

      Wie: Rechte Maustaste auf der Datei  ==> Menü  "Compile"

   2. Ziel: Pseudo-Maschinencode erzeugen / neutrale Darstellung

      "x64\\Debug\\Program.obj"

      Linux: .o  

      Das ist ein spezifiziertes Format: IOFF // COFF

      The Common Object File Format (COFF) is a format for executable, object code
      oder
      Intel OMF (Object Module Format)

D) Wer erzeugt den finalen Maschinencode: 2 Tools: Compiler + Linker

   i) Können Fehler vorhanden sein:

      zB gibt es main nicht : Einsprungpunkt // Anfang des Programms.

      Abbruch


   ii) Keine Fehler: Haben ein Maschinenprogramm erzeugt.

   Wie: Rechte Maustaste auf dem Projekt ===> "Erstellen"

   Ziel: Eine Datei mit der Endung .exe   (( Unix: KEINE Endung ))

E) Maschine: Hardware: CPU -  Recheneinheit -  Register / Memory / IO / …

   Jede Maschine / CPU (Recheneinheit) hat ihre eigenen Sprache: Befehlssatz / CPU Instruktionen: 

   Beispiel:  Intel:  MOV, JMP, CMP, ..

Beispiel:

    int a = 1;
